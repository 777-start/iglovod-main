# Игловод — демонстрационная главная страница

Независимая версия согласуемого прототипа главной страницы компании «Игловод». Проект не использует ChatGPT Sites, внутренние адреса или платформенный backend.

## Стек

- HTML5;
- CSS3;
- JavaScript без фреймворков;
- локальные изображения PNG и JPG;
- Node.js 22+ для локального сервера и production-сборки;
- GitHub Actions для публикации на GitHub Pages.

У проекта нет runtime-зависимостей и нет папки `node_modules` в комплекте. Стили и клиентский JavaScript находятся внутри `index.html`, как в утверждённой версии прототипа.

JSX/TSX и компоненты фреймворка не требуются: опубликованный интерфейс является статической одностраничной версией. Платформенная оболочка ChatGPT Sites намеренно не включена, поэтому проект запускается независимо.

Шрифты задаются локальным системным стеком `Inter`, `Segoe UI`, `Arial`, `sans-serif`; внешняя загрузка шрифтов или CDN не используется.

## Структура


## Локальный запуск

Требуется Node.js версии 22 или новее.

```bash
npm install
npm run dev
```

После запуска откройте:

```text
http://127.0.0.1:5173
```

## Проверка ресурсов

```bash
npm run check
```

Команда проверяет наличие всех локальных изображений, используемых страницей, точное совпадение регистра имён, Linux-совместимые пути на латинице без пробелов, а также отсутствие служебных URL ChatGPT Sites, временных файловых адресов и ссылок на локальный сервер.

## Production-сборка

```bash
npm run build
```

Готовая статическая версия создаётся в папке:

```text
dist/
```

Проверить production-сборку локально:

```bash
npm run preview
```

Адрес предпросмотра:

```text
http://127.0.0.1:4173
```

Содержимое папки `dist` можно разместить на любом обычном статическом хостинге.

## Публикация на GitHub Pages

1. Создайте новый репозиторий на GitHub.
2. Загрузите в него всё содержимое этой папки.
3. Убедитесь, что основной веткой является `main`.
4. В репозитории откройте **Settings → Pages**.
5. В поле **Source** выберите **GitHub Actions**.
6. Выполните push в ветку `main` или вручную запустите workflow **Deploy to GitHub Pages**.

Пути к изображениям относительные, поэтому страница работает как в корне домена, так и по адресу вида `username.github.io/repository-name/`. Дополнительная настройка `base path` не требуется.

## Формы

Форма работает в безопасном демонстрационном режиме:

- браузерная проверка обязательных полей сохранена;
- после отправки выводится демонстрационное сообщение;
- данные не передаются на сервер и не отправляются во внешние сервисы.

Для рабочего сайта обработчик формы можно заменить интеграцией с CRM или собственным backend.
